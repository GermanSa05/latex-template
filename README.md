# LaTeX Thesis Template

Clean starting point for engineering theses and technical reports: title page, abstract,
numbered table of contents, figures and tables with working cross-references, and a BibTeX
bibliography.

## What's inside

| File | Purpose |
|---|---|
| `main.tex` | Document skeleton with one example of equation, table and figure |
| `references.bib` | Sample bibliography in BibTeX format |

## How to use

1. Upload the folder to [Overleaf](https://www.overleaf.com) or open it locally
2. Set the compiler to **pdfLaTeX**
3. Replace the content, keep the structure

Tested with TeX Live 2024 and Overleaf.

## What it demonstrates

- Automatic numbering and cross-references (`\label` / `\ref` / `\eqref`)
- Booktabs tables instead of the LaTeX defaults
- A bibliography that compiles without manual ordering
